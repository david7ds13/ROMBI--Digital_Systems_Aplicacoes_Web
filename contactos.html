Perguntas frequentes

O que é uma placa NFC?

É uma placa com um pequeno chip. Quando se aproxima um telemóvel, o perfil abre sozinho, sem instalar nenhuma app.

Funciona em todos os telemóveis?

Quase todos os telemóveis recentes têm NFC. Para os outros, a placa tem também um QR Code.

Se mudar o menu tenho de comprar outra placa?

Não. Basta alterar o perfil no painel e a mudança aparece logo.

Quanto custa?

Criar o perfil é grátis. Só se paga a placa ou o cartão NFC.
