# ROMBI - Perfis Digitais

Website para criar perfis digitais de negócios e profissionais (menu, Wi-Fi, horário, avaliações Google, contactos), que abrem com um toque NFC ou com QR Code.

Projeto de Aplicações Web - Licenciatura em Informática de Gestão, ISCAC, 2026/2027.

## Aluno

- 2022120635 - David Santos Soares - TP2

## Tecnologias

- HTML5
- CSS3 (flexbox)
- JavaScript (a partir da Entrega 3)

## Páginas

- `index.html` - página inicial
- `templates.html` - escolher um template ou começar do zero
- `criar-perfil.html` - formulário para criar o perfil e pré-visualização
- `perfil.html` - perfil público de exemplo (o que o cliente vê)
- `painel.html` - painel do dono do negócio
- `admin.html` - administração da plataforma
- `contactos.html` - perguntas frequentes e formulário
- `entrar.html` - login

Os mockups estão na pasta `mockups` (ficheiro `rombi-mockups.drawio`).

## Como abrir

Abrir o `index.html` no browser ou usar o Live Server no VS Code.
